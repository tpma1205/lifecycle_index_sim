# 指數投資配合生命週期模擬器 (Life-Cycle Strategy Simulator)

這是一個基於 **生命週期投資法 (Life-Cycle Investing)** 理論開發的專業退休財務模擬工具。透過蒙地卡羅模擬 (Monte Carlo Simulation) 與動態槓桿配置，協助使用者評估在不同市場情境下的退休成功率與資產走勢。

## 🌟 核心特色

- **蒙地卡羅模擬**：執行 1,000 次獨立的路徑模擬，涵蓋樂觀 (P75)、中位數 (P50) 與悲觀 (P25) 三種市場情境。
- **生命週期槓桿配置**：實作 Ayres & Nalebuff 的理論，在投資生涯早期透過槓桿放大曝險，平滑一生中的時間分散化風險。
- **自動建議配置**：根據使用者的「人力資本 (Human Capital)」與目前資產比例，自動計算符合理論的理想槓桿倍數。
- **動態提領評估**：結合退休後的通膨調整提領 (如 4% 法則)，精準計算「資金未耗盡存活率」。
- **專業可視化儀表板**：使用 Chart.js 呈現清晰的資產生命週期預測曲線。

## 🛠️ 技術棧

- **Logic**: Pure JavaScript (ES6+)
- **Charts**: [Chart.js](https://www.chartjs.org/)
- **Icons**: [Lucide Icons](https://lucide.dev/)

## 📖 理論背景

本模擬器參考以下核心金融學術理論：

1.  **Life-Cycle Investing** (Ian Ayres & Barry Nalebuff): 提倡年輕時應使用槓桿以達到時間上的資產分散。
2.  **Trinity Study (4% Rule)**: 關於退休提領率與資產續航力的經典研究。
3.  **Time Diversification**: 討論長期持有股票如何有效降低報酬的不確定性。

## 🚀 如何使用

1.  **基本現況**：輸入您的當前年齡、現有淨資產以及每月可投入的金額。
2.  **市場預期**：設定預期的年化報酬率、波動率 (標準差) 以及預估通膨率。
3.  **退休目標**：定義您的理想退休年齡、目標資產基準以及退休後首年的預算需求。
4.  **槓桿配置**：
    - 可點擊 ⚡ 按鈕由系統根據「人力資本」邏輯自動填寫建議槓桿。
    - 亦可手動調整各年齡層的投資曝險比例 (例如 2.0x 代表 200% 曝險)。
5.  **執行模擬**：點擊「執行模擬運算」即可即時生成分析結果與圖表。
